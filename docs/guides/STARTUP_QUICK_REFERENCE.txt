│ 📦 STEP 1: ADD TO WINDOWS STARTUP                               │
└─────────────────────────────────────────────────────────────────┘

  1. Press: Win + R
  2. Type:  shell:startup
  3. Press: Enter
  4. Right-click → New → Shortcut
  5. Browse to: E:\DanfosalApp\DanfosalStartup.bat
  6. Name: "Danfosal EasyPOS Pipeline"
  7. Properties → Run: Minimized
